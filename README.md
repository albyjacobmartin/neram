# Neram

/n̪eːɾɐm/

"Neram" (நேரம் or നേരം) translates to time, period, or daytime in South Indian languages like Tamil and Malayalam.

# Pomodoro

/ˌpɒməˈdɔːrəʊ/

Pomodoro literally means "tomato" in Italian, but today it most commonly refers to the Pomodoro Technique, a popular time management method.
